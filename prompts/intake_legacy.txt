Respond with ONLY a single JSON object, no markdown formatting, no code fences, no commentary before or after. The JSON object must have exactly these fields:

{
  "title": "short opportunity name",
  "problem": "the concrete problem being solved, 1-2 sentences",

    "value": 1-5,

    "time_to_result": 1-5
  }
}
